# Enlace — Landing Page

Landing page do programa **Enlace**, de desenvolvimento humano e psicossocial (Jadi, psicóloga).

## Estrutura

Site de página única (`index.html`), autossuficiente — todas as imagens e a logo estão embutidas em base64 no próprio HTML, sem dependências externas além das fontes do Google Fonts (Manrope + Plus Jakarta Sans).

Seções, em ordem:
1. Cabeçalho (nav fixo)
2. Hero
3. Sobre o Enlace
4. Como funciona
5. Para quem é
6. NR-1 / Legislação
7. Investimento
8. CTA final
9. Rodapé

## Publicar no GitHub Pages

1. Faça o push deste repositório para o GitHub
2. Vá em **Settings → Pages**
3. Em "Source", selecione a branch `main` e a pasta `/ (root)`
4. Salve — o site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`
